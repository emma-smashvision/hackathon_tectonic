# Game critique — round 2

## Q1. Keep one road in 3D; cut the city

**Keep optional Drive, including a maximum 25-second pitch beat.** Crowd and pitch correctly reject the asset city. They have not shown why a readable road must lose driving. The user's enthusiasm deserves one concrete implementation before we abandon it.

Click Drive on Tom's Moving house road. The same month markers become posts; aggregate ghost riders travel towards the energy stop. One removal van and a meter distinguish the road. Tap **Show me ahead**: the car travels for 3 seconds and stops beside an amber surprise marker. The existing evidence sheet opens. Switch Map: same stop, note and actual position. Holding an arrow offers assisted movement; nobody must steer to learn anything.

This makes “people travelled before you” tangible. It is the same information with motion, not another financial system. No asset neighbourhood, free-roaming junction hunt, tutorial, scores, collision penalties or debrief. No Drive for care or Large & simple.

**Conditions:** complete Atlas → stop → note → next person first. Include Drive only if an unfamiliar viewer identifies road, position and purpose within 10 seconds without coaching. Require shared gated evidence, reduced-motion fallback and a clean timed rehearsal. If it fails, concede removal from the pitch and entry points. An 8-hour deadline cannot justify rushing this addition.

## Q2. Everyday plus one confirmed life road on day one

Accept pitch's narrower implementation. Several concurrent life roads need consent, date and duplicate-action rules; they are not necessary to prove the concept. Allow unlimited previews without changing the confirmed pointer.

Tom first sees **Moving house · before your move on 1 November · You told Kate**, followed by his position, crowd explanation and next 3 stops. **Moving house / Everyday** are named switches; Moving house is selected. **All roads** stays visible. Everyday opens October's seasonal road, not a second competing feed. A proposed replacement requires confirmation; never silently overwrite a road.

## Q4. Find a road first; Kate can use the same matcher

Use **Find a road** in All roads for the jury's free text. Return existing catalogue matches, then confirm road and stage. A local synonym table is enough; ambiguity returns choices, unsupported situations return no match. Care disclosure requires consent.

Matching returns a road ID, never statistics. The selected road loads versioned, gated evidence from the existing engine. Any future Kate model gets the same catalogue-only contract. Pending roads have no public evidence. Neither search nor Kate changes actual position during exploration.

## Q5. Steal and veto

**Steal UX's 5-second orientation test:** can someone name the road, position and benefit? Apply it before visual polish; use its 10-second equivalent for optional Drive.

**Veto pitch's upward timeline.** Use UX's now-to-later downward reading order in 2D. Drive moves forward through the same numbered months. Different camera angles must not introduce different chronology.
