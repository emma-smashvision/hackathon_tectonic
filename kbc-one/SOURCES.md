# Sources

KBC One (v5) is a new, untracked folder. It was built from copies of our existing apps on **18 October 2026**. Nothing was committed, and the originals were only read (read-only git with `--no-optional-locks`, so no lock files were left behind).

| Source | Where | State when copied | Copied into |

| **Kate adaptive home** (round two) | `hackathon_tectonic-worktrees/kate-adaptive-home` | Branch `kate-adaptive-home` @ `6b809a9` **plus the uncommitted round-two work** (16 modified files, 2 new) | `src/kbc/`, `src/app/api/kbc/`, `src/lib/kate/limits.ts`, `public/characters/`, the stage CSS in `src/app/globals.css` |
| **Hindsight v4** | `hackathon_tectonic/hindsight-v4/` | Untracked folder in the main repo | `src/hindsight/` (from `src/engine`, `src/components`, `src/game`), `src/app/api/notes/`, `src/app/icon.svg`, `tests/` |
| **v1 stage** (round one) | `hackathon_tectonic/` main @ `235e856`, `src/components/prototype/` | Committed | The stage's pattern: animated story on the left, portrait rail on the right, drawer |

Because the Kate round-two work is not committed anywhere, this folder is also a second copy of it.

## Changed from the copies

**Kate**

- `types.ts`, `personas.ts`, `ui/stage.ts`: Nadia (care persona) added; `care` flag.
- `compose.ts`: the care home (calm, advisor first, no suggestions).
- `kate.ts`: road facts in Kate's facts; a `drive` proposal, checked in code.
- `server/service.ts`: the grounding check on Kate's replies.
- `ui/App.tsx`, `ui/Screens.tsx`, `ui/icons.tsx`: Road in the nav, the look-ahead card, the landscape phone, Kate's Look ahead card, the drawer's three tabs; the stage story with `motion` as in v1.
- `src/app/globals.css`: the stage part of the worktree's `globals.css` (its first 317 lines). `layout.tsx`: both apps' fonts, title "KBC One".
- `ui/kbc.src.css`: two CSS animations removed (`motion` animates the story now); scoped under `.ph` into `kbc.css`.

**Hindsight**

- `engine/roads.ts`, `lives.ts`, `placement.ts`, `components/stage/Atlas.tsx`: a new Moving house road (Tom) and an Everyday-only road (Lina, Margaret, Sofie).
- `engine/life.ts`: the household can be passed in, so each person's own money drives their road.
- `engine/format.ts`: Belgian number format (`€ 1.987`).
- `components/store.tsx`: one store per person; a sandbox for drives with "Make this my plan".
- `components/phone/*`, `game/hud/*`: embedded in the KBC phone; "Back to the app"; no driving for care roads and Large & simple.
- `game/network.ts`, `game/next.ts`: Moving house takes an avenue in the City; drives on the Everyday Road start at this month.
- `tests/*.test.ts`: import paths; the City test follows the avenue order.
- `src/app/api/notes/route.ts`: import path only.
